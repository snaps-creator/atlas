# Проверки Beta 6 — 20 сентября 2026

## Подтверждено

- Frontend: 6 тестов пройдено; production frontend собран.
- Rust: 36 тестов пройдено. Новая регрессия: отключение со старым tun-guard.active не запускает помощник/UAC и удаляет устаревший маркер.
- Интеграционные тесты используют реальный Mihomo для проверки конфигурации, HTTP DIRECT/BLOCK и SOCKS5 UDP на localhost. Они не доказывают Windows full-tunnel.
- scripts/test-tun-adapter.ps1: изолированное создание Atlas-TUN успешно от администратора и SYSTEM. В обоих случаях адаптер Up, после остановки ядра адаптер удалён, default/split-default маршруты не изменились.
- Изолированный тест не включает auto-route, DNS-сервер или WFP-блокировки. Временное задание SYSTEM не имеет триггеров и удаляется после теста.

## Исправления, требующие сквозной проверки

- Служба DEMAND_START вместо AUTO_START; установщик больше не запускает её.
- Ограниченные права пользователей: запуск/запрос состояния, без изменения службы.
- Служба завершается после сессии; следит за завершением клиентского процесса.
- До готовности TUN системные блокировки не устанавливаются.
- Выход из трея не отменяется из-за ошибки отключения/сохранения.
- Проверка API ядра больше не подменяет проверку успешного создания TUN.
- При ошибке TUN возвращается исходная ошибка Mihomo; неудачная сессия завершается.
- Проверка маршрутов /1 отказывает в подключении поверх другого full-tunnel.

## Не подтверждено

Ошибка со скриншота Atlas-TUN не найден, 0x57 не воспроизвелась в тестах без маршрутизации. Первичная ошибка исходной сессии не сохранилась.
Нужны установка Beta 6, реальное подключение с пользовательской конфигурацией при отключённом Clash, disconnect/quit/crash, повторное подключение и перезагрузка.
До этой проверки нельзя утверждать, что исходный сетевой сбой полностью исправлен.
