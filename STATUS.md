# Атлас — состояние работ, 17 сентября 2026

Изменения внесены в существующий проект React / TypeScript / Tauri / Rust / Mihomo.
Полная сетевая приёмка ещё не завершена. Успешная сборка не является доказательством отсутствия утечек.

## Реализовано

- Привилегированный TUN-помощник, проверка сторон IPC, системная маршрутизация IPv4/IPv6, DNS по TCP/UDP, блокировка IPv6 при отключении его поддержки.
- Постоянные фильтры WFP: блокировка сети при аварии, восстановление разрешений ядра при повторном запуске, снятие защиты при явном отключении. Реальная работа этих фильтров под UAC ещё не проверена.
- Проверка серверов через Mihomo: два HTTPS-адреса, до четырёх попыток, отдельные ошибки контроллера, числовая задержка, очередь до трёх проверок. В TUN IPC ядра последовательно обслуживает запросы.
- SVG-флаги по метаданным, названию и локальной GeoIP-базе для IP. Неизвестные записи отображаются глобусом.
- Нормализация правил и детерминированный порядок по специфичности, обнаружение конфликтов и удаление дублей при импорте.
- Компактная таблица, массовая смена маршрута, отключение, удаление и поиск.
- Общая модель визуальных правил и YAML, редактор с подсветкой, номерами строк, поиском, отменой/повтором, форматированием и проверкой.
- Быстрое добавление сайтов, процессов, EXE из диалога и перетаскиванием. Список работающих процессов и программ из реестра с настоящими иконками. Программы без регистрации в реестре могут потребовать выбора EXE.
- Переносимый YAML без подписок и секретов; импорт с preview и выбором маршрута конфликтов.
- Создание правил из подключений, отображение процесса, домена/IP, TCP/UDP, версии IP, маршрута, сервера и правила.
- Главный переключатель VPN, русская навигация, состояния, действия и tray.
- Сохранён прежний формат настроек. Исходный зашифрованный payload дополнительно сохраняется в migration_backups; обычная история содержит 20 состояний.
- Автоматическая проверка новых правил: очередь до двух проверок, HTTP-задержка и статус сайта, анализ ограниченного журнала ядра в памяти, предложения связанных доменов из ресурсов страницы, перенаправления и связанных ошибок. Добавление только по выбору пользователя. Для приложений и сетей используются реальные соединения; при их отсутствии результат — «нет соединений». Проверки, созданные без подключения, ожидают подключения в текущей сессии.

## Проверено

- 29 тестов Rust и 4 теста TypeScript прошли.
- Mihomo действительно запускался в интеграционном тесте: проверка YAML, применение настроек, переключение селектора, откат некорректной конфигурации, DIRECT/BLOCK на локальном HTTP и UDP-эхо через SOCKS5.
- Новый интерфейс запускался в Windows: подписка сохранилась; добавление двух вариантов URL дало одно нормализованное правило; таблица и YAML совпали; неправильный YAML отклонён; Ctrl+Z работает; список процессов и иконки загружаются; восстановлены настройки до тестового правила.
- После визуальной проверки исправлены контраст YAML, высота списка приложений и оставшиеся английские подписи. Эти исправления включаются в итоговую сборку.

## Осталось подтвердить на реальной сети

В Windows активен туннель Mihomo другого VPN. Пользователю предложено отключить его для изолированной проверки Атласа и подтвердить UAC. Другой VPN не отключался автоматически.

Нужны: реальное TUN-подключение; Telegram TCP/UDP; браузер, Electron, PowerShell/curl и WebSocket; захват пакетов для DNS/IPv6; авария ядра и блокировка утечек; восстановление сети; реальная задержка серверов; автопроверка сайта на рабочем VPN; импорт на втором ПК; перезагрузка и удаление установщика с активной защитой.

Диагностика показывает «Не проверено», когда не хватает наблюдений. HTML не раскрывает все динамические API/WebSocket-домены. HTTP 403/429 может быть ограничением IP или защитой сайта; дополнительные правила не гарантируют устранение.

Из первоначального большого задания также остаются отдельные функции, не входившие в последние правки: подписанные автообновления, полноценные rule packs, расширенный мастер и часть автоматизации подписок. Сертификата подписи дистрибутива нет.
