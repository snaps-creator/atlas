# Atlas Alpha 2.0.1 — внутренний статус

Версия пакета: 2.0.1-alpha.1. Основа — локальная переработка Beta 20.1.1.

Текущее исправление: результаты массового пинга доставляются событиями по каждому узлу. Идентификатор пакета и ревизия защищают от устаревших результатов; ошибка завершения пакета сохраняет уже полученные измерения. Очередь остаётся ограниченной шестью работниками; автономная проверка использует одно временное ядро без TUN.

Незавершённая приёмка основы: полный транзакционный откат сетевой сессии, единый планировщик всех операций, аварийные сценарии и установка/обновление/удаление. CEF-хост использует предварительную версию Tauri; Windows Chromium sandbox требует отдельного решения. Полная приёмка этих пунктов не заявляется данным PR.

Работающая пользовательская установка не заменяется при подготовке PR. Локальные диагностические отчёты, установщики, временные файлы и кэш сборки исключены из Git.
