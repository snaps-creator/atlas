# Установка Atlas 2.4.2

Используйте `Atlas_2.4.2_x64-setup.exe` из проверенной сборки 2.4.2. Установщик поддерживает обновление существующего Atlas, сохраняет конфигурацию и credentials, проверяет запуск новой версии и использует транзакционный rollback при ошибке. Запуск установки прерывает VPN-соединение; запускайте его, когда готовы к переключению.

Локальная сборка: `./scripts/build.ps1`. Она восстанавливает зависимости, выполняет проверки и собирает транзакционный установщик в новом target. Подписанная сборка: `./scripts/build-local-signed.ps1` с заранее настроенным Tauri signing environment. Установщик автоматически не запускается.

Метаданные и ограничения проверки: [RELEASE-2.4.2.md](docs/RELEASE-2.4.2.md). Исторический комплект ниже сохранён для регрессионных тестов и не представляет текущую версию исходников.
# Исторический офлайн-комплект Atlas Alpha 2.2.5

1. Скачайте Code → Download ZIP с GitHub.
2. Распакуйте архив полностью.
3. Запустите **Install Atlas.exe**. Папка **installer** должна лежать рядом.

Установщик можно запускать при работающем Atlas и включённом туннеле. Новый независимый модуль завершает принадлежащие установке процессы и восстанавливает сетевое состояние до замены файлов. При переходе с версии, чья кнопка обновления блокируется старой ошибкой очистки, запустите этот полный установщик поверх установленной версии.

Это настоящий Windows x64 EXE. Он собирает установщик из локальных частей в папке installer, проверяет встроенные размер и SHA-256, затем открывает обычный мастер установки Atlas. Интернет, Git, Node.js и Git LFS для установки не нужны. Используется встроенный в Windows 10/11 .NET Framework 4.x. При повреждённой или неполной загрузке запуск отменяется с сообщением. Отмена UAC также не запускает установку.

Размер и SHA-256 полного установщика записаны в `installer/manifest.json`. Подпись обновлений находится в `installer/atlas-setup.exe.sig` и проверяется публичным ключом Atlas.

Запускатель и данные хранятся обычными Git-файлами, каждый меньше 100 МиБ. ZIP исходников содержит реальные байты независимо от настройки «Include Git LFS objects in archives». Старые ZIP нужно скачать заново.

`SHA256SUMS.txt` содержит хэш запускателя. Windows Authenticode отсутствует: Windows может показывать неизвестного издателя. Подпись обновлений Tauri не является Authenticode.

Проверки без установки:

```powershell
node scripts/verify-offline-installer.cjs
./scripts/test-offline-installer.ps1
```

Обновление комплекта из нового подписанного установщика:

```powershell
./scripts/build-offline-installer.ps1 -Installer path/to/signed-setup.exe
```

После обновления нужно пересчитать SHA256SUMS.txt, закоммитить Install Atlas.exe и весь installer/, скачать ZIP ветки с GitHub и повторить проверки. `--verify` проверяет сборку данных и SHA-256 без запуска мастера установки.
