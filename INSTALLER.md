# Установка Atlas для Windows

**[Официальная загрузка — GitHub Releases](https://github.com/snaps-creator/atlas/releases/latest)**

Для Windows 10/11 x64 скачайте из Assets полный EXE. Планируемый файл версии 2.5.1 — `Atlas-Setup-2.5.1.exe`; эта версия пока не опубликована. ZIP исходников не содержит готовый установщик.

Один офлайн-пакет включает Atlas UI, Atlas.Service.exe (существующая служба AtlasNetworkService под SYSTEM), Mihomo, Xray с данными, CEF, AtlasMaintenance.exe и AtlasUpdater.exe, который также служит стабильным launcher. При установке отдельные зависимости из сети не скачиваются.

Мастер поддерживает новую установку, обновление и повторную установку. Транзакционный updater проверяет receipt каждого файла, останавливает старую сессию, активирует неизменяемый каталог версии, проверяет службу/UI и сохраняет журнал для rollback. При ошибке восстанавливается предыдущая версия. Источники, секреты в Windows Credential Manager, избранное, выбор сервера и параметры запуска не являются файлами установочного payload. Не удаляйте их вручную перед обновлением. Подробности — [UPDATES.md](docs/UPDATES.md).

Подписи `.sig`, подписанный update-manifest и SHA256SUMS позволяют проверить пакет. Подпись обновлений Atlas отличается от Authenticode: сертификат издателя Windows сейчас не заявлен. До публикации проверенные кандидаты доступны только как временные Actions artifacts для разработчиков.

## Сборка и проверка

`scripts/build-release-installer.ps1 -Clean -Signed` использует новый target, собирает внутренний Tauri payload, формирует единый транзакционный EXE, проверяет версии/архитектуру/receipt/повреждение файлов и подписывает пакет. Закрытый ключ передаётся через настроенную среду CI, в исходниках его нет.

`scripts/test-packaged-installer.ps1` проверяет полный пакет и CEF/службу в изолированных режимах. `scripts/test-connected-upgrade.ps1` запускается только на одноразовом GitHub Windows runner: проверяет обновление, сохранность синтетических данных, startup, rollback, reinstall и uninstall. На рабочем компьютере эти installed tests запрещены защитой самого сценария.

Готовые EXE, подписи и части payload не коммитятся и не загружаются в Git LFS. Публичное распространение — только GitHub Releases. Публикация запускается вручную из main после merge и отдельного разрешения; подготовка PR ничего не публикует.
