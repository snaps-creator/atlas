# Atlas

**Atlas** — VPN-клиент для Windows с быстрым выбором сервера, гибкими правилами маршрутизации и понятной диагностикой соединения. Добавьте подписку, подключитесь и управляйте трафиком из одного приложения: вручную, автоматически или по правилам для конкретных сайтов и программ.

Текущая версия исходников — **Alpha 2.1.3**. Atlas построен на React, TypeScript, Tauri 3 + CEF и Rust; для сетевой работы использует Mihomo и Xray.

## Что удобно в Atlas

- **Подключение без ручной настройки ядра.** Добавьте ссылку на подписку или совместимый профиль, выберите сервер и включите VPN в главном окне.
- **Автоматический выбор сервера.** Режим AUTO проверяет задержку и ищет более отзывчивый узел. Порог поиска настраивается; при потере ответа Atlas ищет замену независимо от порога. Режим FAILOVER сохраняет рабочий резерв, а нужный сервер всегда можно выбрать вручную.
- **Все серверы под рукой.** Узлы из нескольких подписок отображаются в общем списке. Есть поиск, избранное, сортировка по задержке и проверка отдельного сервера или всего списка. Результаты появляются по мере проверки; недоступный узел получает статус «Таймаут».
- **Правила для приложений и сайтов.** Направляйте отдельные программы, домены и IP-сети через VPN, напрямую или в блокировку. Правила можно менять в таблице либо в YAML; поддерживаются импорт, экспорт и проверка выбранного правила.
- **Три режима на главной странице.** «Правила» применяет ваши маршруты, «Глобальный» направляет трафик через выбранный сервер, «Прямой» отправляет его без VPN. Переключение режима применяется к новым соединениям.
- **Видно, что происходит.** Главная показывает график отправки и скачивания за 10 минут, скорость в КБ/с, объёмы за сессию, активные соединения и память ядра. Отдельно можно проверить HTTP-доступность ChatGPT, Grok, Gemini, YouTube и Telegram.
- **Помощь при сбоях.** Раздел «Диагностика» проверяет состояние соединения и сохраняет TXT-отчёт с журналами, маршрутами, DNS, DHCP и сетевыми проверками. Для нескольких компьютеров в локальной сети есть защищённый паролем просмотр состояния и отчётов доступных устройств.
- **Повседневные настройки.** Доступны светлая, тёмная и системная темы, значок в трее, запуск с Windows, автоподключение и восстановление предыдущей сессии.
- **Обновления внутри приложения.** Atlas проверяет GitHub Releases при запуске и затем каждые шесть часов; доступное обновление устанавливается по вашей команде.

Задержка сервера — это время HTTP-проверки через него, **не** скорость скачивания и не гарантия качества любого сайта. Проверка доступности сайта также измеряет HTTP-ответ, а не ICMP-пинг; ответы 403/429 могут означать ограничения самого сервиса.

## Установка

Нужна **Windows 10/11 x64**. Скачайте [последний выпуск](https://github.com/snaps-creator/atlas/releases/latest) либо выберите **Code → Download ZIP** на странице репозитория. Для установки из ZIP полностью распакуйте архив и запустите **Install Atlas.exe** из корня; папка `installer/` должна находиться рядом. Этот установочный комплект работает без подключения к интернету.

Windows может показать «Неизвестный издатель»: у установщика пока нет сертификата Authenticode. Подпись обновления Atlas и подпись издателя Windows — разные вещи. Детали установки и проверки файлов — в [INSTALLER.md](INSTALLER.md).

## Подписки и совместимость

Atlas принимает подписки Clash/Mihomo YAML, Xray JSON, Base64 и отдельные proxy URI. Серверы подключённых подписок собираются в единый список. Подписки можно обновлять вручную; поддерживаются обновление по расписанию, резервный адрес, разрешённая провайдером смена адреса и отдельный User-Agent.

Для VLESS через Xray поддерживаются RAW/TCP, WebSocket, gRPC, HTTPUpgrade, XHTTP/SplitHTTP и mKCP, включая предусмотренные профилем TLS/REALITY и параметры fragment/noises. Импорт клиентского Xray JSON сохраняет совместимые DNS, маршрутизацию и исходящие соединения. Это импорт клиентских профилей, а не запуск произвольной серверной конфигурации. [Форматы, пределы и ограничения](docs/HAPP-COMPATIBILITY.md).

## Маршрутизация под ваши задачи

В разделе «Правила» можно отправить отдельное приложение или сайт через VPN, оставить его на прямом соединении либо заблокировать. Поддерживаются процесс, точный домен, суффикс или часть домена, IP-сеть и сочетание процесса с доменом. Более конкретные правила имеют приоритет; порядок строк YAML сам по себе приоритет не задаёт.

```yaml
version: 1
default-route: direct
rules:
  - process: Telegram.exe
    route: proxy
  - domain-suffix: openai.com
    route: proxy
  - domain-suffix: example.com
    route: block
```

`default-route: direct` оставляет обычный трафик напрямую и отправляет через VPN только то, что выбрано правилами. Для всего трафика через VPN используйте глобальный режим. Таблица и YAML изменяют одну модель настроек; ошибки и неразрешённые конфликты не заменяют действующие правила.

## Диагностика и данные

В «Соединениях» видны программа, адрес, протокол, применённое правило, маршрут и сервер. Если подключение работает неправильно, сохраните TXT-отчёт **во время сбоя, до перезагрузки**. Он помогает отделить проблемы локального сетевого пути от отказов проверяемых VPN-узлов, но один отчёт не доказывает состояние всех серверов провайдера. [Состав отчёта и интерпретация](docs/INCIDENT-DIAGNOSTICS.md).

Настройки и резервные состояния хранятся локально с защитой Windows DPAPI; ссылки подписок — в Windows Credential Manager. Переносимый экспорт правил не включает подписки и пароли. Диагностический TXT скрывает секреты и ссылки подписок, но содержит локальные IP-адреса и имена сетевых адаптеров — учитывайте это перед отправкой отчёта.

## Сборка из исходников

На Windows 10/11 x64 нужны Node.js, Rust MSVC, Microsoft C++ Build Tools и Windows SDK.

```powershell
./scripts/build-local.ps1
```

Скрипт готовит локальный установочный комплект. Порядок выпуска подписанного обновления описан в [UPDATES.md](docs/UPDATES.md). Разработка сетевой части и восстановление после аварий продолжаются; текущие пределы испытаний описаны в [статусе проекта](docs/STATUS.md). Успешная сборка и локальные тесты сами по себе не подтверждают безотказную работу на каждой сети и конфигурации Windows.
