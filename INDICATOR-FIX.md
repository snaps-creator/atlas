# Исправление индикаторов — 17 сентября 2026

- Исправлено кодирование пробелов в имени узла в URL пути Mihomo: %20 вместо +. На одном активном сервере воспроизведено: старый запрос HTTP 404, исправленный 269 мс.
- HTTP 400/401/403/404 контроллера больше не классифицируются как недоступность VPN-сервера.
- Проверки приложений возобновляются после запуска и обновляются каждые 10 секунд при открытых правилах. Отсутствие соединений обозначено как ожидание трафика; ошибка API выделена отдельно.
- В связанных ошибках учитываются только warning/error строки.
- В боковой панели только фактический сервер из цепочки ATLAS/AUTO/FAILOVER, его HTTPS-задержка и переключатель. Разрешение цепочки каждые 5 секунд, измерение задержки каждые 30 секунд. При отсутствии данных показан прочерк.

Проверено: 29 Rust тестов и 6 frontend тестов. Интеграционный тест отдельного Mihomo исключён из повторного запуска: порт 17890 занят рабочим Atlas. Исходный запуск подтвердил именно конфликт порта, а не ошибку проверки.
Живые измерения без переключения активного VPN: Прага 303 мс, Амстердам 332 мс, Фуджейра 926 мс.
Обновлённый интерфейс требует установки новой сборки; работающий экземпляр не остановлен во время сборки, чтобы сохранить связь.

Последующее уточнение: проверки правил выполняются исключительно по общей кнопке «Проверить правила». Автоматические эффекты и таймер удалены. Каждый запуск получает свежие настройки и результаты ядра, сбрасывает предыдущие результаты и показывает время запуска. Сборка интерфейса и 6 frontend тестов проходят.

Дополнение: Clash Verge использует unified-delay=true, а Atlas ранее измерял первый HTTPS-запрос вместе с установлением соединения. Включён unified-delay в генераторе конфигурации, добавлена проверка этого поля. На одном узле до изменения 288 мс; после — 69, 67, 66 мс. Сравнение Праги через оба ядра на одинаковом URL gstatic: Atlas 106 мс, Clash 82 мс (последовательные измерения, Clash TUN включён). Значения не являются ICMP-пингом. Изменение применено к активному ядру; для сохранения после перезапуска подготовлено обновление.
