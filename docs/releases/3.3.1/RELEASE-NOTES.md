Atlas 3.3.1 исправляет установку и обновление, когда Windows использует другую учётную запись администратора. Приложение запускается от владельца рабочего стола, его настройки и подписки сохраняются в его профиле. Повышенные права Проводника больше не приводят к отказу проверки ограниченного пользователя.

В корне репозитория доступен `Install Atlas.exe`: один файл загружает официальный полный пакет, проверяет подпись и запускает мастер. Для офлайн-установки используйте `Atlas-Setup-3.3.1.exe` из этого релиза. Обновление поверх прежней версии не требует удаления Atlas или его настроек.
