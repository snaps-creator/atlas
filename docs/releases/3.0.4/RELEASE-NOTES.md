# Atlas 3.0.4

- Проверка задержки подтверждает HTTPS-ответ через конкретный сервер. Устаревший успешный результат не скрывает последующий сбой; таймаут остаётся видимым во время повторной проверки.
- Повторный запуск и запуск через ярлык восстанавливают существующее окно Atlas. Новые ярлыки используют стабильный путь запуска.
- Исправлено ожидание ответа групповой проверки серверов: завершение всех таймаутов больше не оставляет контроллеру лишь 500 мс для возврата общего результата.
- Проверка обновления в Windows CI включает версии 3.0.1, 3.0.2 и 3.0.3. Повторное использование уже опубликованной версии блокируется до сборки.

Наличие этих изменений в исходниках не подтверждает успешную проверку итогового установщика. Фактические результаты кандидата фиксируются в PR; публикация выполняется отдельно после завершения проверок.
