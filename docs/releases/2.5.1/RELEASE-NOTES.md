# Atlas 2.5.1

URL-подписки и VLESS-ключи объединены в один список источников и серверов. Одна кнопка добавления предлагает оба типа. Выбор сервера и избранное сохраняются при обновлении источников.

VPN сохраняет намерение подключиться, ждёт доступную сеть и возобновляет ограниченные попытки после подтверждённой смены сети. Ручное отключение отменяет восстановление. Плановые проверки не требуют предварительного ручного ping; измерение задержки само не переключает исправное соединение. Оптимизация задержки включается отдельно.

Исправлены IPC rejection, потеря restore intent при startup, backup churn при refresh errors и компенсация credential writes. Startup errors видны в интерфейсе, uninstall проверяет зарегистрированные user profiles, история диагностики объединяет повторяющиеся ошибки.

Один полный офлайн-установщик Atlas-Setup-2.5.1.exe содержит UI,сетевую службу,Mihomo,Xray,CEF,maintenance/updater. Обновление выполняется транзакционно с проверкой файлов и rollback. Источники,credentials,избранное,выбранный сервер и startup preferences сохраняются. Установка может прервать VPN для переключения версии.

Реальный reboot/power loss,hidden CEF workload и multi-user offline-hive acceptance остаются ограничениями, указанными в release readiness. Подпись Atlas updates отличается от Authenticode. Перед публикацией обязательны signed build и installed acceptance на соответствующем main SHA.
