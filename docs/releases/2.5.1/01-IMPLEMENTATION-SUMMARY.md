# Atlas 2.5.1 — реализация

Статус: кандидат, релиз не опубликован. Основа — main 365b912 и кандидат 2.4.3 49dfcde7666a58847c48c65a8a29570174316710. Ветка release/atlas-2.5.1 создана в отдельном worktree; изменения исходной рабочей ветки не затронуты.

URL и VLESS равноправны: один диалог добавления, общий список источников, общий пул серверов, поиск/избранное/сортировка и идентичность, ограниченная исходным источником. Импорт транспорта, существующий SYSTEM service и транзакционный updater сохранены.

Добавлено сохранение VPN intent до попытки соединения, отдельная запись видимости окна, восстановление ограниченного retry budget после подтверждённой смены сети, единый владелец recovery и fair reserve scheduler. Ручные измерения не являются командой выбора маршрута. Оптимизация задержки требует явного включения и по умолчанию выключена.

Исправлены отказ IPC-клиента, churn конфигурационных backups, компенсация WinCred при сбое записи, ошибки регистрации startup, учёт offline профилей при uninstall и повторяющиеся incident errors. Открытые вопросы и границы доказательств перечислены в отдельных отчётах; никакие результаты 2.4.2 не выдаются за проверку 2.5.1.

Один публичный установщик: Atlas-Setup-2.5.1.exe. Старый установщик и split payload удалены из текущего Git tree; история Git не переписывается. README ведёт на официальную страницу последнего опубликованного релиза. Merge, тег v2.5.1 и публикация требуют отдельного разрешения.
