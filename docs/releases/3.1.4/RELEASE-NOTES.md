# Atlas 3.1.4

- Возвращена методика пинга из 3.0.3: HTTP-запрос к Cloudflare по прогретому соединению. Порог автопоиска снова использует сопоставимую величину, без добавленного в 3.0.4 времени установки HTTPS-соединения.
- Весь список серверов проверяется раз в минуту независимо от состояния выбранного узла. Активный сервер проверяется каждые 10 секунд.
- Поиск замены при отказе или высоком пинге сохранён и не ждёт минутного обхода. Отдельный непрерывный обход резервов убран.
- Свежесть измерений согласована с минутным обходом; новая ошибка сразу скрывает прежний успешный пинг.
- Проверка ответа 204, конкретного исходящего узла и отдельная HTTPS-проверка маршрута и туннеля сохранены.
- После мерджа обновления снова собираются и публикуются автоматически, только после обязательных проверок и подписи. Обновление с 3.0.4 включено в приёмочные проверки.

Риск: физическая перезагрузка или потеря питания Windows во время обновления не проверены. Автоматические проверки завершения процессов, восстановления журнала и установленного приложения остаются обязательными.
